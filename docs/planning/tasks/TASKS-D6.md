## The standard exit gate

**Every task below closes on the same four conditions**, so they are not repeated per row:

1. Its acceptance criteria all pass
2. `npm run verify` is green
3. Claude review PASS **and** OpenAI review PASS
4. No findings outstanding

The **Exit adds** column lists only what a task requires _beyond_ that. An empty cell means the
standard gate is the whole gate.

> **D6 V2 is a policy, not a task.** "A test for every correction" is enforced through each
> task's acceptance criteria, every one of which must fail on today's code.

## Deferred: C22, league points at the year boundary

**Not in D6, and not in the beta.** Recorded here so the reasoning is not rediscovered.

The [2026-08-31 ruling](../specs/2026-08-31-vision-gaps-design.md) says a season's **league
points** halve at the end of the year, and that the halving applies to **ranking only**, leaving
the member's spendable balance whole.

The app cannot do that today. `functions/rewards.js:4` computes a member's redeemable balance as
`leaguePoints26` plus earned task points minus points already spent, so league points are also
half the wallet. Halving them now would halve unspent purchasing power, which is the one outcome
the ruling forbids.

The same ruling defers the **wallet split** to a future milestone and sets one hard constraint:
**the split must land before the first halving ever runs.** So both pieces are end of year work,
in this order.

| ID         | Task                              | Blocked by                     |
| ---------- | --------------------------------- | ------------------------------ |
| _(future)_ | Split the wallet from the ranking | Backlog, end of year milestone |
| **C22**    | Halve league points at year end   | The wallet split               |

Two properties the halving needs whenever it is built: it must be **idempotent**, since running
it twice must not halve twice, and the rollover is a **code change**, because `leaguePoints26` is
a literal field name in the rules file, seven Cloud Functions, four test files and D8's seeding
query.
