## The standard exit gate

Every task closes on: acceptance criteria pass · `npm run verify` green · Claude review PASS
and OpenAI review PASS · no findings outstanding. **Exit adds** lists only the extras.

**Two conditions apply to every task in this sprint**, from the sprint's binding rule and its
verification table:

- The primitive is registered in `.design-sync` **in the commit that creates it**, and consumed
  at one real call site in the same change. The build compiles CSS from `src/` only.
- Checked in **light and dark**. Six of the eight original audit passes found light-theme-only
  defects, so a dark-only check proves nothing.

Rows built in groups 1 and 2 also have to pass at **360px** before they count as done.
