## The standard exit gate

Every task closes on: acceptance criteria pass · `npm run verify` green · Claude review PASS
and OpenAI review PASS · no findings outstanding. **Exit adds** lists only the extras.

**Two conditions apply to every task in this sprint:**

- **No card data touches the app or the database.** Stripe-hosted surfaces only.
- **No Stripe key appears in a `VITE_` variable.** Keys are server secrets. A key in a client
  env var is shipped to every browser.

Everything here runs in **Stripe test mode**. The live-money proof belongs to
[M6](../VISION.md) on staging, not to this sprint.

## What this sprint is not

**No membership fee, ever.**

**No court booking.** Booking a court gets its own tab, **Book My Court**, built later. D9 only
makes sure the payments record can hold a court booking row, that the row carries a **type**, and
that it never offers a cancellation path.
