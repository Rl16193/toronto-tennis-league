# Documentation archive

This directory contains completed, superseded, or historical engineering evidence. It is retained
for source traceability and is not the active work queue.

## Active working documents

- [Documentation home](../README.md) — architecture, diagrams, domain rules, engineering guidance,
  runbooks, active registers, and their maintenance contract.
- [Master backlog](../BACKLOG.md) — every open item, its permanent `BLG####` ID, source task/bug
  references, status, and acceptance evidence.
- [Future work](../FUTURE-WORK.md) — product work intentionally outside the closed delivery program.

## Archived collections

- [`anuj/`](anuj/) — completed founder and `dev-anuj` takeover evidence, including the
  [DC00 foundation reconciliation](anuj/DC00-DEV-ANUJ-FOUNDATION.md).
- [`planning-2026-08-23/`](planning-2026-08-23/) — the closed planning-branch package and D1-D5
  sprint source documents.

Architecture, diagrams, domain rules, engineering guidance, and runbooks are maintained as active
references directly under [`docs/`](../README.md), not in this archive.

Moving a document here does not erase its source identifiers or Git history. Any unfinished outcome
from an archived document must be represented in `BACKLOG.md` before the source is treated as closed.
